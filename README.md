# 🚖 Uber Ride Analysis Dashboard

### 📊 Power BI | DAX | Power Query

This project presents an interactive Power BI dashboard developed to analyze Uber ride booking data. The dashboard provides insights into booking performance, revenue trends, vehicle utilization, rider metrics, location-based patterns, and ride cancellations through a combination of KPI tracking and interactive visualizations.

---

## 🛠️ Tools Used

* Power BI
* DAX
* Power Query
* Data Modeling

---

## 📌 Key Metrics

* Total Bookings
* Completed Bookings
* Completion Rate
* Total Revenue
* Revenue per Ride
* Average Ride Distance
* Cancellation Rate
* Lost Revenue

---

## 📑 Dashboard Pages

### 📊 Overview Analysis

Provides a high-level summary of booking performance, revenue, ride completion, and distance metrics.

### 🚗 Vehicle Performance Analysis

Analyzes bookings, revenue contribution, and performance across different vehicle categories.

### 💰 Revenue Analysis

Tracks revenue trends and key financial performance indicators.

### 👤 Rider Analysis

Examines rider-related metrics and booking behavior.

### 📍 Location Analysis

Highlights booking activity and performance across pickup and drop-off locations.

### ❌ Cancellation Analysis

Evaluates cancellation rates, cancellation reasons, and their impact on revenue.
